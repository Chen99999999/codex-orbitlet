# Security

For a possible vulnerability, use GitHub's private vulnerability reporting for this repository when available. Do not put authentication tokens, account identifiers or private application data in a public issue. If private reporting is unavailable, open an issue containing only a request for a private contact method, without vulnerability details or secrets.

Useful non-sensitive details include the Orbitlet version, Windows version, whether the issue concerns window attachment or local preview, and a minimal reproduction using synthetic data.

Orbitlet does not expose account-changing RPC methods. Reports about arbitrary file access, credential exposure or escaping the local-preview boundary are particularly relevant. There is no published response-time or support guarantee.
