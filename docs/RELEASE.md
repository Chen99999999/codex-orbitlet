Orbitlet's first public release: a tiny white-and-gray quota companion that stays with the Codex desktop window.

- Centered 5-hour and weekly remaining percentages, with the last successful update time.
- Native window attachment, foreground-only visibility and client-area docking.
- Optional automatic start with Codex; independent mode remains available.
- Official read-only quota integration, unknown states and offline retention.
- 100 × 102 px standard view and 88 × 90 px compact view.
- 48 offline assertions for quota, lifecycle and attachment behavior.

Download the Windows ZIP, extract the whole folder, open Codex and run `Orbitlet.exe`. The binary is unsigned. Windows .NET Framework and a signed-in official Codex installation are required.

This is an independent community project, not an official OpenAI product. Please report compatibility issues without attaching credentials or personal account data.
